# 🎱 YOLOv13 桌球自动计分系统

> 基于 **YOLOv13 + Flask + Vue + Ollama** 的智能桌球自动计分系统，实现桌球目标检测、自动计分、犯规提示、视频复盘以及 AI 桌球教练等功能。

## 📌 项目简介

本项目是一套面向标准八球场景设计的桌球智能辅助系统。

系统通过 **YOLOv13** 对桌球场景中的母球、目标球和球袋进行检测，并结合目标跟踪与计分逻辑实现自动计分。

同时，系统采用 **Vue + Flask** 前后端分离架构，并集成基于本地 **Ollama** 的「桌球教练智能体」，为用户提供桌球规则问答、击球思路和比赛策略建议。

### 核心功能

- 🎯 YOLOv13 桌球目标检测
- 🧮 自动计分与比分实时更新
- ⚠️ 犯规标记与手动比分修正
- 📹 实时摄像头检测
- 🎬 本地视频检测与复盘
- 🔄 视频暂停、继续、重新播放、进度拖拽
- 📤 本地视频动态更换
- 🔴 实时比赛录制
- 🤖 Ollama 本地「桌球教练智能体」
- 💬 桌球规则问答与策略分析
- 🖥️ Vue 可视化交互界面
- 🔌 Flask 后端 API 服务

## 🚀 运行环境

论文项目采用 Python 3.9 环境，并使用 PyTorch、OpenCV、Flask、Ultralytics 等核心依赖。

建议创建虚拟环境：

```bash
conda create -n billiard python=3.9
conda activate billiard
```

安装主要依赖：

```bash
pip install torch
pip install ultralytics
pip install opencv-python
pip install flask
pip install requests
```

如果使用 AI 桌球教练功能，还需要安装并启动 **Ollama**，并准备对应的本地大语言模型。

## ✨ 项目特点

### 1. 自动计分

通过 YOLOv13 检测桌球目标，并结合运动状态与入袋判断实现自动计分。

### 2. 实时检测

支持摄像头实时输入，检测结果直接显示在 Web 页面中。

### 3. 视频复盘

支持本地比赛视频检测，并提供暂停、进度拖拽、重新播放和视频切换功能。

### 4. AI 桌球教练

通过本地 Ollama 大模型提供桌球规则、战术和击球思路方面的智能问答。

### 5. 人机协同

考虑到复杂场景下可能存在误检或漏检，系统保留了手动加减分和犯规标记等功能。
